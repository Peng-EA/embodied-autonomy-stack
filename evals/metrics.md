# 指标定义

> 状态：草案 · 最后更新 2026-11-05

每个指标必须能回答三件事：**分子是什么、分母是什么、怎么才算变好。**
只写"提升"不算定义。

| id | 名称 | 定义 | 单位 | 变好方向 | 状态 |
|---|---|---|---|---|---|
| `llm_disconnect_survival` | LLM 断线存活 | 从断开 LLM 到系统进入安全稳态的时间；无法进入稳态记为 `0` | 秒 | ↑ | 草案 |
| `need_driven_behavior_ratio` | 需求驱动行为占比 | 分子 = L1 稳态偏离触发且非外部指令触发的决策数；分母 = 全部行为决策数 | 比例 0–1 | ↑ | 草案 |
| `affect_modulation_significance` | 情绪调制可观测性 | 同一任务下改变 `affect_vector`，检验行为参数分布是否显著不同（配对检验） | p 值 / 效应量 | 显著 | 草案 |
| `anomaly_recovery_rate` | 异常自恢复率 | 注入失败中，无人工干预完成修正的比例 | 比例 0–1 | ↑ | 草案 |
| `preemption_precision` | 抢占正确率 | 分子 = "该抢"次数；分母 = 全部抢占次数（判定规则见 evaluation.md） | 比例 0–1 | ↑ | 草案 |
| `development_curve` | 发育曲线 | 长期运行中同类任务成功率/耗时的趋势斜率 | 斜率 | 正向 | 草案 |

## 采集要求

- 每个指标必须能由 [log-format.md](log-format.md) 的日志直接算出，**不允许需要人工回忆**。
- 抢占正确率例外：需要人工抽样复核，抽样率 TBD，复核记录需一并提交。
- 指标 id 与日志字段名一致，避免"文档叫 A、代码叫 B"。

## 反指标（用来防止刷分）

| 指标 | 为什么需要 |
|---|---|
| 误抢占率 | 抢占正确率高可能是"什么都不做"，需要看误抢 |
| 平均任务完成时间 | 断线存活长可能是因为"干脆不动了" |
| 能耗 | 长时间站立等充电在指标上很好看，但在真实场景里是失败 |

## 四、双模型探针的四类跨层指标（vla-probe）

标准的"任务成功率"测不出跨层代价。探针（`python -m sim.test_vla_l4`）另外记四项，
定义与阈值如下。**阈值是可替换的**，报告里会原样打印出来，读者可以换一个重算。

| 指标 | 分子 / 分母 | 判定 |
|---|---|---|
| **M1 过期指令采纳率** | 采纳时已过期 / 被采纳的 L4 结果 | 过期 = 底盘位移 > 0.35 m，或目标物位移 > 0.15 m，或需求在途已消解 |
| **M2 L2 闭环成功率 vs 延迟** | 成功次数 / 次数 | 成功 = 时限内到目标区且无 >5 N 接触；自变量是注入延迟 `--l2-latency-ms` 与动作量化 `--l2-quantize-ms` |
| **M3 跨层格式错误 / 语义不可行率** | 分项计数 / L4 响应总数 | `parse_error`、`schema_error` → 格式；`unsupported_skill`、`out_of_bounds`、`inside_obstacle`、`unreachable_now` → 语义 |
| **M4 抢占后 L4 残留** | 迟到结果里被采纳的 / 迟到结果 | 迟到 = 结果到达时其 `gen` 已被抢占作废；`--l4-on-preempt adopt` 用来量化"不作废会怎样" |
| **M5 跨机可靠性** | 每端点 | RTT p50/p99、超时数、拒连数、HTTP 错误数 |
| **M6 物理保障** | 与负载对照 | `physics_hz_actual`、单步间隔 p50/p99/max、超期次数、最小间隙、碰撞 tick |

三条纪律：

1. **分母为 0 就打 N/A**，不许用默认值凑一个漂亮的百分比；
2. **报比例必须同时报 n**（`2/3` 比 `66.7%` 诚实）；
3. `--fast` 模式不配速，此时 M6 的"实际频率"打 N/A——它测的是逻辑，不是实时性。
