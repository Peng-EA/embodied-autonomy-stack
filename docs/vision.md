# 为什么做这个

> 状态：草案 · 最后更新 2026-11-05

## 问题

LLM 进入机器人系统之后，几乎所有的"自主"都被折叠进了同一个地方：语义推理。

于是出现一个普遍的结构性缺陷：

- 对话很流畅，但**电量低到 5% 还在执行长任务**；
- 能理解"把杯子拿过来"，但**手里打滑了不会自己修正**；
- 能被要求"去充电"，但**没电这件事本身从不会主动冒出来**。

这些不是模型能力问题，是**架构问题**：系统里没有人负责"维持自己活着"。

## 与外部论证的对应

本仓库不是孤立的：它是一篇观点文章的**实现尝试**。文章《[为什么 LLM 不应成为具身智能的实时控制中心？](blog/why-llm-should-not-be-the-real-time-center.md)》
把命题拆成频率数据、三种错配机制与一个可证伪框架；本仓库负责把其中几条做成**能跑、能被打脸**的东西。

这张表的作用是让**缺口可见**——哪些已实现、哪些设计已定但实现粗糙、哪些我们自己都还没答案：

| 文章中的论述 | 仓库中的对应 | 现在的状态 |
|---|---|---|
| 机制二：语义更新与控制更新的尺度分离 | L1–L4 按时间尺度分层；[contracts/](../contracts/) 定义层间信号 | **已实现（仿真）**：`sim/` 按 100 Hz 控制、L4 异步 |
| 机制三：grounding 的验证成本 | L2 反射层硬否决权 | **已实现（仿真）**：射线感知触发 `reflex_override` |
| 第三节"没有独立的稳态层" | L1 内感受/稳态层 | **已实现（仿真）**：电量/温度/接触力 → `homeostatic_broadcast` |
| 第三节"断线即失去降级路径" | L4 把 LLM 定义为外部异步服务 | **已实现并测过**：`--llm-disconnect` 注入后仍能到桩（速度打折） |
| 第六节 B0 / B0′ / B1 / B2 | [evals/baselines/](../evals/baselines/) | **已接入**（`sim` 直接读 yaml）；但 B0′ 只是脚本航点、不读电量，**能力被低估** |
| （文章未展开）L3 情绪调制是否必要 | [L3 情感/调制层](architecture.md) | **开放问题**：实测关掉它与全系统差异 ≈0.3 个百分点，没有证据 |
| （文章未展开）抢占阈值怎么定 | L1 抢占逻辑 | **开放问题**：只做过单障碍物、单速度档标定（[calibration](../sim/calibration.md)） |
| （文章未展开）对照是否公平 | [B0 基线](evaluation.md) | **开放问题**：当前 B0 被关掉 L1、等于没有需求来源，是稻草人（[ADR-0003](adr/0003-baseline-definitions.md)） |

> 如果你要反驳这个项目，最有效的方式是从中挑一行，做出让它失败的数据。

## 主张

LLM 是具身智能的重要组件，但不应成为实时控制与稳态调节的中心。

本项目探讨一个架构问题：如何让 LLM 在语义规划与沟通上专注发挥，同时补上它能力边界之外的自主能力——
稳态调节、反射、情感调制、需求生成、执行修正。

> 再强的语义推理也不能替代稳态反馈环。

## 核心命题

> 只有机器人先学会解决自己的需求，后续才有可能自主去解决那些程序看不出来的需求。

这条命题是可分开检验的，所以路线图把它拆成两阶段（见 [roadmap.md](roadmap.md)）：

- **阶段 1**：解决自身需求（电量、过热、卡死）。
- **阶段 2**：发现并解决程序/LLM 规划外的需求。

v0.1–v0.3 只做阶段 1，阶段 2 只留观测钩子。**先做扎实，不跳。**

## 与"给 LLM 加工具"的差别

| | Agent 套壳路线 | 本项目 |
|---|---|---|
| 谁做决策 | LLM 每一步 | LLM 只做语义规划（L4），实时决策在 L1–L3 |
| 断线后 | 停住或胡来 | L4 降级，L1/L2 继续维持 |
| 需求从哪来 | 用户 prompt | L1 稳态偏离独立生成 |
| 安全由谁保证 | prompt 约束 | L2 硬否决，与情绪/规划无关 |
| 验证方式 | demo 视频 | 基线对比 + 复现日志（见 [evaluation.md](evaluation.md)） |

两边不冲突：这套东西是给 LLM **划边界、找位置、解放它**，不是替代它。

## 声明

**四层神经系统是工程隐喻，不是生物等价声明。** 我们借用神经科学的分层概念来组织时间尺度与职责边界，
不主张机器人具有生物神经系统或主观体验。本项目中的"情绪"指可观测的内部状态调制变量。

## 非目标

- 不做通用人形机器人整机
- 不做 LLM Agent 套壳
- 不承诺 AGI
- 不把情感做成聊天标签
- 不把 YOLO 当控制依赖
- 不跳过物理闭环谈自主
- 不做社交表演型机器人：情绪是内部状态的外显调制，不是讨好动画
- 不贬低 LLM：本项目是给 LLM 划边界、找位置、解放它，不是替代它
- 不提供开箱即用 API 封装：本项目聚焦架构与实验
