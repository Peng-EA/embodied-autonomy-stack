# ADR-0009: 动作退场必须先过 settle 判据（MIMIC / IK → HOLD）

- 状态：草案（未签字） · 日期 2026-11-09

## 背景

[safety.md](../safety.md) 第 4 条硬约束：动作结束禁止瞬时切回 HOLD，顺序是命令斜坡到 0 → 速度/力矩回稳 →
才允许切。依据是维护者演示台实测：MIMIC 播完立刻切 HOLD，机器人**直接摔倒**。

现状（`sim/env/g1_modes.py`）：POLICY 退场有 P5 三段式（命令 ramp → 刹到 |v| < 0.05 → 非冻结交接）；
MIMIC（`_mimic_exit`）与 IK（`_ik_exit`）只有 `_ramp_s = RAMP_S = 0.20 s` 的**目标插值**，
**没有任何 settle 判据**——alpha 一归零就交 HOLD，谁也没问过姿态/支撑回稳没有。

P3-f 在 MuJoCo 里把这个缺口复现出来了（实验脚本在 `.tmp/p3f/`，**仓库文件零改动**）。

## 证据

> 2026-11-09 · MuJoCo 4.0.0 · `selfcheck --mimic` 路径 · clip `bonus/B_HandsUp`（441 帧，退场 t=9.922 s）
> 方法：外部脚本 monkeypatch `g1_modes.RAMP_S`（只改这一次运行），退场后再观察 3 s；摔 = pelvis z ≤ 0.5。

| RAMP_S | z_min（全程） | 摔 | 摔倒 − 退场 | Δctrl@退场 | 接触法向峰值 |
|---|---|---|---|---|---|
| 0.00（压掉 ramp） | 0.0388 | 是 | +1.76 s | **0.775 rad / 2 ms** | 661 + 598 N |
| 0.20（**现默认**） | 0.0649 | **是** | +1.12 s | 0.218 | 436/56 → 465/0 N |
| 3.00 | 0.0577 | 是 | +1.11 s | 0.219 | — |
| 10.00 | 0.0572 | 是 | +0.97 s | 0.219 | 左脚离地 0.220 m |

（0.05 / 0.10 / 0.40 / 0.80 / 1.50 / 6.00 也各跑一次，全摔，z_min 0.0407–0.0599，摔倒 +1.01–2.15 s。）

**这一档复现不出来（如实报）**：另两段**怎么退都不摔**（0.00 / 0.20 各一次）——`bonus/B_HandsChop`（1765 帧 / 35.3 s）
z_min 0.7852 / 0.7849、退场后最大倾角 4.3° / 4.1°；`dance/J_Dance0_StepTouch`（1949 帧）0.7883 / 0.7880、4.9° / 3.2°。

**为什么现有自检看不见**：`--mimic` 报 `z_min=0.7766 / return_to_hold=0.208 s / PASS`；它的循环在
`mode.mimic_done`（alpha 归零，t=10.12 s）就 break，而最低点 0.0649 出现在 **t=11.04 s**。
**窗口在"交接完成"那一刻关掉，摔倒正好在窗口外。**不修这条，任何 settle 方案都会被误判成"不摔"。

## 机制

1. 退场那一帧**看起来是稳的**：z 0.7841 m、倾角 1.65°、|v| 0.035 m/s、双脚承重（273 / 122 N）——
   任何"切换瞬间采样一次"的门都会**当场误开**。
2. 要插值的是目标位形：片尾姿态与 keyframe `stand` 的腿差 0.11–0.24 rad（hip_roll 0.231、hip_pitch
   0.110/0.175、knee 0.222/0.208、ankle 0.153/0.137、hip_yaw 0.244），增益同时从训练 kp（14.3–99.1）
   换到 HOLD kp = 500。
3. 这点腿差**把左脚拉离地面**：默认 0.20 s ramp 里 +0.05 s 左/右脚 436/56 N、+0.20 s 变成 0/465 N
   （右脚单脚承重），左脚抬到 0.129 m 后**再不落地**（10 s ramp 版本抬到 0.220 m）。HOLD 是纯 pose hold、没有平衡控制，
   倾角则 1.7° → 20°（+0.40 s）→ 57°（+1.10 s）单调涨，+0.354 s `right_knee_joint` 越限，1.12 s 后 z ≤ 0.5。
4. 压掉 ramp 是另一条路、同一个根因：同一 Δ 目标在**一个物理步（2 ms）**内变成 0.775 rad 控制阶跃（默认
   0.218 的 3.5 倍），接触法向力瞬时 661 + 598 N，机器人被蹬得双脚贴地滑行 0.23 m/s，1.76 s 后倒。

一句话：**摔不是"ramp 太短"，是退场目标位形把一条腿抬离地面，而换控制源时没有任何判据拦它。**

## 决策（草案）

1. MIMIC / IK 退场固定为：目标斜坡 → **settle 判据** → 切 HOLD；判据不过不许切。
2. 判据**不许只看切换瞬间**：须在 HOLD 增益下"试保持" T_hold，窗口内倾角单调不恶化、双脚接触占比 ≥ 90%、
   速度 < 0.05 m/s，才允许 alpha 归零。
3. `selfcheck --mimic` 观察窗延长到"退场 + 3 s"（**测量变更，不是控制变更**）。
4. 判据不过只能留在原机构继续跟或明确 FAIL，**不许静默切换、不许降阈值凑过**。

## 候选方案

**A. ramp → settle 判据 → HOLD（试保持）** —— 如决策 1–2。
代价：退场从 0.21 s 涨到 ≥ 0.7 s，`duration_s` / `return_to_hold_s` 语义要跟着改，状态流加 3 个观测量。
失败模式：试保持窗口里已经摔了才判死，等于"摔了才知道"；且 MIMIC 退场时原机构已停产，**没有可回退的控制器**。

**B. 固定最短 settle 时长（不判定，只等）** —— 退场前原地保持终态 T ≥ T_min 再走现有 ramp。
代价：最小、一行改动、不要新观测量。失败模式：**片尾本身单脚/前倾时，等多久都不回稳**——本切片已部分证伪：
冻结终态目标保持 5 s 摔；ramp 拉到 10 s 仍摔（左脚离地 0.220 m）。单靠"等"大概率无效。

**C. 运动学减速曲线（在参考/轨迹空间减速，跟踪闭环不拆）** —— 不插值执行器目标，而是给动作源喂一段
"片尾 → stand"的参考段（限加速度、保支撑），策略继续闭环跟踪；alpha 只降增益、不换目标几何。
代价：要么离线给每段 clip 生成减速段（新数据 + 重验"frames 必须播到底"），要么在 ONNX 外另写参考外插
（等于多个轨迹规划器，属新模块 + 新 ADR）。失败模式：外插落在训练分布外 → 另一种失稳；clip 时长语义变，
七项判据全部重算。本切片只测了"目标空间"的两种替代（冻结 5 s、非冻结闭环交接），**都摔**——方向应指向参考空间。

## 可判死的验收判据

| # | 判据 | 判死条件 | 本切片现状 |
|---|---|---|---|
| 1 | settle 关（RAMP_S=0）必须摔 | 退场后 3 s 内 z_min > 0.5 → 复现不成立，方案不用评 | 已成立（0.0388） |
| 2 | settle 开必须不摔 | z_min ≤ 0.5，或退场后 3 s 倾角 > 10°，或双脚接触占比 < 90% | 待测（A/B/C 都没测过"开"） |
| 3 | 不许退化 | P0a 四项、`--walk` 六项、`--collide`、`--ik`、`--stop-abrupt` 任一项变 | run1/run2 逐项相同（p95 类墙钟数除外） |
| 4 | 反作弊 | 只拿"切换瞬间"的速度/接触当判据 | exit 帧速度 0.035、双脚着地、倾角 1.65°，仍摔 → 判死 |
| 5 | 只拉长 ramp 不算方案 | 必须报 RAMP_S = 0.2 / 3 / 10 三档 | 10 s 也摔（0.0572）→ 判死 |

任一条不过 = 该方案判死并写进"被否掉的方案"；**不许改判据数值让它过**。

## 后果

### 正面

- 退场第一次有"回稳"这门课，而不是一段固定 0.20 s 的插值。
- 观察窗延长后，自检不可能再把"摔在窗口外"报成 PASS。

### 负面（必须写）

- 退场变慢：8.8 s 的动作多 ≥ 0.5 s，`return_to_hold ≤ 2 s` 的余量吃掉一半。
- 判据要接触力 / CoM，两者现在 `selfcheck` 只采样不判；进状态流要同步 `docs/interfaces.md`。
- **本切片没测出任何"开 = 不摔"的方案**：A/B/C 取舍仍靠判断，不靠数据；IK 只读代码没跑（同套 `_ramp_s`，未验证）。
- 判据本身是新失败面（误判"不摔" → 更晚才倒）。

## 被否掉的方案

- **D. 拉长 RAMP_S**：0.2 / 3 / 10 s 全摔（0.0649 / 0.0577 / 0.0572）。时长不是变量，目标几何才是。
- **E. 冻结终态目标等它自己稳**：`--hold-final 5 s --freeze-target` 在保持段内就摔。
- **F. 把 P5「非冻结交接」照搬到 MIMIC**：ramp 期间每控制帧刷新动作源目标，仍摔（z_min 0.0419，+2.03 s）。
  P5 治的是 POLICY 的速度动量，治不了"目标抬腿"。

## 如果这个决策是错的，会看到什么

- 若"必须是判据、不是时长"错了：某个 T_min（0.5–1 s）就让 B_HandsUp 不摔 → 候选 B 一次过闸，A/C 是过度设计。
- 若"参考空间才治本"错了：A 的试保持能过闸 → C 的减速段是白写一条数据管线。
- 若观察窗这个前提错了：延长窗口后 `--mimic` 依然全绿 → 证据链要重做（先查外部脚本）。
