# ADR-0001: 四层是工程隐喻，不是生物对应

- 状态：已接受
- 日期：2026-11-05

## 背景

项目的核心叙事借用了神经科学的分层概念：内感受/稳态、反射、情感/动机、规划协调。
这套说法有两个好处：**好记**、**能解释为什么越快的事越不该经过 LLM**。

风险也很明确：一旦被读成"机器人有生物神经系统 / 有主观体验"，就会引来两类错误质疑——
一类是"你们在宣称机器有意识"，另一类是"神经科学的层级不是这么分的，你们抄错了"。
我们既没有这个主张，也不打算在生物学上辩护。

## 决策

**四层是组织时间尺度与职责边界的工程隐喻。**

- 分层的判据是**时间尺度**（10–100 ms / 0.1–1 s / 1–10 s+），不是生物解剖；
- "内感受""反射""情感"这些词只描述**可观测的状态变量与调制关系**，不主张主观体验；
- 文档与首页必须显式声明这一点（`docs/vision.md`、`README.md`、站点页脚）。

## 后果

### 正面

- 借来的词降低了沟通成本：说"L2 反射"比说"毫秒级本地否决控制器"快得多。
- 时间尺度这条判据是**可检验**的：如果某类事件被证明不需要这个分层也能做好，分层就该被砍掉。
- 声明边界之后，讨论可以集中在"时间尺度选得对不对"，而不是"你们是不是在说机器人有意识"。

### 负面

- 隐喻会被过度解读：已经出现"情绪向量 = 机器有感情"的读法，需要反复澄清。
- 与生物神经系统的具体结构（如丘脑、杏仁核）**没有**对应关系，任何"按脑区实现"的建议都不适用。
- 四层数为 4 是拍定的；如果仿真里发现需要第 5 层（例如专门的"疼痛"层），这个 ADR 要作废重写。

## 被否掉的方案

| 方案 | 否掉原因 |
|---|---|
| 用纯工程术语（实时层 / 认知层 / 规划层） | 准确但不易记，且在跨领域沟通时丢失了"为什么快慢要分开"的直觉 |
| 直接对标某个生物神经系统模型 | 会把工程约束绑死在生物学的争议上；且我们无力做生物学辩护 |
| 不分层，只分"快路径/慢路径" | 无法表达"L3 只调制不越权"这类职责约束 |
