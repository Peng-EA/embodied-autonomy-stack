## 约定

| 项 | 约定 |
|---|---|
| 文件名 | `kebab-case-en.md`（英文 slug，便于 URL 与分享） |
| 开头 | 一行状态：`观点文章（假说） · 日期 · 作者` |
| 引用 | **能点开、说法与原文一致**；做不到就写「待核实」，不许编 |
| 数据 | 必须写清场景（基线/时长/平台），禁止把预期写成实测 |
| 结尾 | 给一个"怎么反驳我"的可执行入口（命令或实验） |
