# 安全与伦理

> 状态：草案 · 最后更新 2026-11-05 · 安全报告流程见 [SECURITY.md](../SECURITY.md)

## 一句话

**情绪影响偏好，不影响安全。**

这句话是架构约束，不是口号。它意味着：情绪向量的任何取值，都不能让一条本该被截断的动作通过。

## 三条硬约束

### 1. L2 硬否决

- 力 / 距离 / 限位阈值可配置，但**配置源只有一个**（安全配置文件），不接受运行时被规划层或情绪层改写。
- 任何情绪或规划状态下的动作，触碰阈值一律截断。
- 否决是**打断**，不是"建议降低速度"。
- 阈值必须来自硬件安全规格或实测标定，**不允许拍脑袋**（见 [architecture.md](architecture.md) TBD 表）。

### 2. 情绪参数裁剪

情绪向量只调制参数，且有上下限与衰减：

| 可调制 | 不可调制 |
|---|---|
| 探索率 | 力阈值 |
| 避障距离（在安全下限之上浮动） | 距离阈值 |
| 交互频率 | 限位 |
| 任务优先级 | 否决逻辑本身 |

- 饱和：所有调制量有硬上下限，不能因为"极端恐惧"而无限保守到停滞。
- 衰减：情绪随时间自然回落，避免状态锁死。时间常数 TBD。
- 违规检测：任何把 `affect_vector` 读进安全判定的实现，视为契约违规（见 [interfaces.md](interfaces.md)）。

### 3. 需求生成的边界

L1 可以生成"我该充电了"，但**不能生成"推开挡路的人"**。
需求到动作之间必须经过 L3（动机）与 L4（规划），并在 L2 处过安全否决。
这条链路上任何一环被绕过，都属于设计缺陷，请按 [SECURITY.md](../SECURITY.md) 私密报告。

### 4. 动作退场必须先 settle

**任何动作结束时禁止瞬时切回 HOLD。** 顺序是：命令斜坡到 0 → 速度/力矩回稳 → 才允许切 HOLD。

- 依据（实测，2026-11-09 维护者在演示台观察到）：MIMIC 播完立刻回 HOLD，机器人**直接摔倒**。
  这和"奔跑不刹车就直接停下会摔"是同一件事：身上的动量还没散，突然换目标就是失稳。
- 现有实现：`sim/env/g1_modes.py` 的 MIMIC 退场只有 `RAMP_S = 0.20 s` 的目标插值
  （`selfcheck --mimic` 报"回 HOLD 0.208 s"），**没有 settle 判据**；POLICY 那条链有 P5 三段式
  （命令 ramp → 刹到 |v|<0.05 → 非冻结交接），MIMIC 与 IK 没有享受同等待遇。
- 任何"突然的结束"或"中间态"同样危险：动作中途被打断、模式在未回稳时就切换，都会让机器人失控。
  所以模式切换点必须只有一个入口，且该入口自带 settle 门。
- 这属于安全敏感变更（见文末"安全敏感变更"）：改它需要 ADR + 可复现的失败注入实验。
- **数值旁证（2026-11-09）**：把 L2 的 settle 窗口从 1.10 s 压到 0.45 s，G1 30 s 跑 5 次有 **1 次直接摔**（z_min **0.0428**，默认窗口 0/5）。
  持权交还得越快，越容易在动量未散时换控制源——窗口长不是保守，是物理。

## 隐私

- 视觉 / 声音涉及人物状态时，日志脱敏。
- 人物状态识别仅用于**交互调制**，不持久化原始音视频。
- 需要留存证据用于安全审计时，留存"结论 + 时间戳"，不留原始素材。

## 可解释日志

每个行为决策必须能回答三个问题：

1. 当时情绪向量是什么？
2. 触发它的需求是什么（`source_need`）？
3. 有没有被谁抢占（哪一层、什么原因）？

日志字段定义见 [evals/log-format.md](../evals/log-format.md)。

## 声明

本项目中的"情绪"指**可观测的内部状态调制变量**，不主张主观体验。
不做社交表演型机器人：情绪是内部状态的外显调制，不是讨好动画。

## 安全敏感变更

以下改动必须附 ADR + 可复现的失败注入实验，不接受仅凭论证合入：

- `contracts/` 中任何带安全语义的字段
- L2 硬否决的判定条件或阈值语义
- L1 抢占优先级规则
- 本文档中的约束原则
