# 术语表

> 状态：草案 · 最后更新 2026-11-05

| 术语 | 解释 |
|---|---|
| **L1 内感受/稳态** | 监控电量、温度、关节应力等内部变量，检测偏离设定点的程度，向全局广播需求信号 |
| **L2 反射** | 毫秒级本地控制策略（PID、阻抗控制、轻量网络），处理避障、平衡、接触修正 |
| **感知前端** | 视觉/声音/本体感知的实时特征提取，输出结构化状态向量；属于 L2/L3 的输入，不直接等 LLM |
| **L3 情感/动机** | 连续情绪状态向量（效价/唤醒/支配等），调制 L2 参数并生成目标候选 |
| **L4 规划协调** | 接收目标候选，协调任务分解，调用异步 LLM 服务，下发执行计划 |
| **抢占** | 高优先级信号（如 L1 广播、L2 中断）打断低优先级层当前行为 |
| **效价 / 唤醒 / 支配** | 情感状态的三维连续变量：愉悦度、激活程度、控制感 |
| **稳态设定点** | 内部变量应维持的目标值或区间，偏离即产生需求 |
| **虚拟内感受** | 为机器人定义的内部状态变量集合，类比生物内感受 |

## 补充条目

| 术语 | 解释 |
|---|---|
| **语义服务（LLM）** | 外部异步能力提供者：只做语义规划与对话，不持有设定点、不生成需求、不改安全阈值 |
| **需求（need）** | 由 L1 稳态偏离产生的内部驱动，先于目标存在。区别于"用户指令" |
| **目标候选（goal candidate）** | L3 输出的"我想干什么"，带优先级与来源需求；尚未经过 L4 的任务分解 |
| **硬否决（hard veto）** | L2 直接截断动作的权限，不需要请求许可，不受情绪或规划状态影响 |
| **可抢占（preemptible）** | 该行为在执行过程中允许被更高优先级信号打断；本项目要求向上传递的信号都具备此性质 |
| **B0 / B0′ / B1 / B2** | 四条对照基线，定义见 [evaluation.md](evaluation.md) |
| **"该抢"判定** | 事后判定规则：不抢占则 1 s 内会发生力超阈值/碰撞/人进入安全距离，则本次抢占是"该抢" |
| **阶段 1 / 阶段 2** | 阶段 1 解决自身需求；阶段 2 发现并解决程序外需求。见 [roadmap.md](roadmap.md) |
| **ADR** | Architecture Decision Record，架构决策记录：把争论的结论落成可引用的文档 |
| **四层神经系统** | 工程隐喻。借神经科学的分层概念组织时间尺度与职责边界，**不是**生物等价声明 |
